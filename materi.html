Materi Komputasi Awan

Pengertian Komputasi Awan

Komputasi awan (cloud computing) adalah penyediaan layanan komputasi seperti server, penyimpanan, basis data, jaringan, dan perangkat lunak melalui internet. Pengguna cukup menyewa dan memakai sumber daya sesuai kebutuhan, tanpa membeli dan merawat perangkat keras sendiri.

Model Layanan

SaaS

Software as a Service. Aplikasi siap pakai yang diakses lewat browser atau aplikasi. Pengguna tidak mengelola server maupun sistem operasi.

Contoh: Google Drive, Gmail, Microsoft 365.

PaaS

Platform as a Service. Platform untuk mengembangkan dan menjalankan aplikasi. Pengembang fokus pada kode, sedangkan infrastruktur dikelola penyedia.

Contoh: GitHub Pages, Google App Engine, Heroku.

IaaS

Infrastructure as a Service. Infrastruktur dasar berupa mesin virtual, penyimpanan, dan jaringan yang dapat dikonfigurasi penuh oleh pengguna.

Contoh: Amazon EC2, Google Compute Engine, Microsoft Azure VM.

Manfaat dan Risiko

ManfaatRisiko
  • Biaya awal rendah (bayar sesuai pemakaian).
  • Mudah ditingkatkan atau dikurangi kapasitasnya.
  • Dapat diakses dari mana saja selama ada internet.
  • Pemeliharaan dan pembaruan dikelola penyedia.
  • Bergantung pada koneksi internet.
  • Risiko privasi dan kebocoran data bila salah konfigurasi.
  • Ketergantungan pada satu penyedia (vendor lock-in).
  • Gangguan layanan penyedia memengaruhi pengguna.
